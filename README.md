# manaba plus（筑波大学）

筑波大学のmanaba（`https://manaba.tsukuba.ac.jp/ct/`）を使いやすくするChromeの拡張機能です。

- **時間割**：ホームの上部（コース一覧と課題の列の上）に、曜日と時限の表で時間割を出します。年度、学期（春・秋）、モジュール（A・B・C）を切り替えられます。
- **課題の締切の色分け**：未提出課題の一覧で、締切までの残り時間に応じて行を色分けし、「残り2日3時間」のような表示を付けます。
- **課題の非表示**：課題ごとに一覧から隠せます。隠した課題は、同じGoogleアカウントでログインした別の端末のChromeでも隠れます。

画面のデザインは、[デジタル庁デザインシステム（DADS）](https://design.digital.go.jp/dads/)の色、フォーカスの表示、部品の寸法に合わせています。

## 入れ方

Chromeウェブストアでは配布していません。手元でビルドして、パッケージ化されていない拡張機能として読み込みます。Node.js 24が要ります。

```bash
npm install
npm run build
```

1. Chromeで`chrome://extensions`を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このリポジトリの`dist`フォルダーを選びます。
4. manabaのホームを開くと、上部に時間割が出ます。

コードを更新したときは、`npm run build`のあと、`chrome://extensions`で拡張機能の再読み込みのボタンを押し、manabaのページを開き直します。

## 使い方

### 時間割

- 開いた日の日付から、年度・学期・モジュールを自動で選びます。休業期間は、直前のモジュールを選びます。
- 手で選んだ年度・学期・モジュールは、その日のうちは保たれます。
- コース名にマウスを重ねると、科目番号、担当教員、時限が出ます。
- 時限が「他0」のコース、時限が空のコース、時限を読み取れないコースは、表の下の「時間外・集中・その他」に出ます。
- 読み込んだコースの一覧は、6時間のあいだ保存しておきます。すぐ読み込み直すときは「再読み込み」を押します。

コースの一覧は、`home__all_y{年度}`のページを読み込んで作ります。このページを読み込んでも、manabaの表示の設定（現在のコース、サムネイルとリスト）は変わりません。

### 課題の締切

| 区分 | 条件（既定） | 色 |
| --- | --- | --- |
| 超過 | 締切を過ぎた | 赤 |
| 緊急 | 24時間以内 | 橙 |
| 近い | 3日（72時間）以内 | 黄 |
| 今週 | 7日（168時間）以内 | 緑 |
| 余裕 | 7日より先 | 灰 |
| 締切なし | 受付終了日時が空 | 淡い青 |

- 残り時間は1分ごとに更新します。
- 「締切順に並べる」をオンにすると、締切の早い順に並べます。締切のない課題は最後です。
- 「非表示」で課題を隠せます。「非表示の課題を表示」をオンにすると、隠した課題が薄く出て、「再表示」で戻せます。
- 隠した記録は、締切から30日たつと自動で消えます。

## モジュールの開始日を年度ごとに直す

今日がどのモジュールかは、モジュールの開始日だけで決めます。各モジュールは、次のモジュールの開始日の前日まで続くものとして扱い、休業期間は直前のモジュールになります（夏季休業は春C、4月の春Aの前は前の年度の秋C）。終了日は、学年暦で確かめにくいため持っていません。

開始日は、次の順に重ねて決まります。後ろのものほど優先します。

1. 目安の開始日（`src/lib/modulePeriods.ts`の`DEFAULT_STARTS`）
2. 拡張機能に入っている、年度ごとの学年暦（同じファイルの`STARTS_BY_YEAR`）
3. 利用者がオプションの画面で直した開始日

| モジュール | 目安 | 2026年度（学年暦） |
| --- | --- | --- |
| 春A | 4月8日 | 4月14日 |
| 春B | 5月21日 | 5月26日 |
| 春C | 7月1日 | 7月2日 |
| 秋A | 10月1日 | 10月1日 |
| 秋B | 11月11日 | 11月12日 |
| 秋C | 1月5日 | 1月6日 |

### 新しい年度の学年暦を入れる（開発者）

大学の学年暦が出たら、`src/lib/modulePeriods.ts`の`STARTS_BY_YEAR`に年度を足します。日付は「MM-DD」で書き、1〜3月の日付は、その年度の翌年の日付として扱います。

```ts
export const STARTS_BY_YEAR = {
  2026: { 春A: "04-14", 春B: "05-26", 春C: "07-02", 秋A: "10-01", 秋B: "11-12", 秋C: "01-06" },
  2027: { 春A: "04-13", /* … */ 秋C: "01-05" }, // 秋Cは2028年1月5日
};
```

`npm test`で、足した開始日が春Aから秋Cへ順に並んでいるかを確かめられます。そのあと`npm run build`でビルドし直します。

### 自分の環境だけで直す（利用者）

1. `chrome://extensions`で、この拡張機能の「詳細」から「拡張機能のオプション」を開きます。
2. 「モジュールの開始日」で年度を選び、各モジュールの開始日を入れます。
3. 「保存する」を押します。

直した開始日は、その年度だけに使われます。「この年度を拡張機能に入っている開始日に戻す」で元に戻せます。

オプションの画面では、ほかに次のことができます。

- 締切の色分けの時間を変える
- 時間割をはじめから開いておくか、土曜の列を常に出すかを決める
- 時間割のキャッシュと、隠した課題の記録を消す

## 開発

| 用途 | コマンド |
| --- | --- |
| 型の検査 | `npm run typecheck` |
| 単体テスト | `npm test` |
| ビルド | `npm run build` |
| 変更を監視してビルド | `npm run watch` |
| アイコンを作り直す（Pillowが要る） | `python3 scripts/make-icons.py` |

```text
manifest.json
icons/                     # 拡張機能のアイコン（scripts/make-icons.py で作る）
src/
├── content/
│   ├── main.ts            # content script の入口
│   ├── router.ts          # ページを判定して機能を選ぶ
│   ├── tokens.css         # DADS のトークン（--mp-*）
│   ├── common.css         # 時間割と課題一覧で共通の部品（ボタン、フォーカスなど）
│   ├── dom.ts / icons.ts  # 要素とアイコンを作る関数
│   ├── timetable/         # 時間割：parser / module / source（取得とキャッシュ）/ render / index / style.css
│   └── assignments/       # 課題：parser / deadline / render / index / style.css
├── options/               # オプションの画面
└── lib/                   # モジュールの開始日（modulePeriods.ts）、設定と入力の検査、chrome.storage のラッパー
tests/
├── fixtures/              # manaba の HTML を基にしたフィクスチャ（個人名は伏せています）
└── *.test.ts
```

DOMが想定と違うときは何もせず、コンソールに`[manaba-plus]`で始まる警告を出します。動かないときは、開発者ツールのコンソールを見てください。

### 確かめたmanabaの構造

2026年11月7日に実際のページで確かめた構造です。manabaが変わって動かなくなったときは、ここと`tests/fixtures/`を直します。

- ホームのコース一覧は`div.contentbody-left`の中の`div.my-infolist-mycourses`。同じクラスで、`my-infolist-deactivecourse`も付いた別の箱がある。
- 年度の`select`のoptionの値は、`home___y2026?chglistformat=thumbnail`のようにクエリが付く。
- 各コースは`div.coursecard`。`dd.courseitemdetail-date`の直下の文字が年度、`span`が「秋C 月5,6、木1,2」の形の時限。
- 未提出課題の一覧は`table.stdlist`。見出し行は`tr.title`で、最後の列`th.th-period-responsive`は広い画面では隠れている。
- 日時は「2026-11-08 23:55」の形（日本時間）。受付終了が空の課題がある。

リスト表示（`chglistformat=list`）のときの構造は、表示の設定を変えないと確かめられないため、まだ確かめていません。今は、表の行からコースへのリンクと時限らしい文字を探す読み方にしています。読めなければ「コース一覧の形式を読み取れませんでした」と出ます。
